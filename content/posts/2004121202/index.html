最近のコメントを表示させようと、巷に出回っているスタイルシートを使おうとすると順序が逆になってしまうという件。これはMovableTypeのバージョンが2.64以降で、データベースにPostgreSQLを使っている場合に発生する問題のようですが、3.11、3.121でも同様に不具合となってしまうようです。
前回、このエントリーで紹介したパッチを当てる方法でいけるのですが、どうも変更が必要なのはContext.pmというファイルだけのようですので、ここに紹介しておきます。

ファイル Context.pm と CONTEXT.PM.ORG を比較しています
***** Context.pm
{ blog_id => $blog_id, visible => 1 },
{ 'aggregate_sort' => { 'column' => 'created_on',
'function' => 'max',
'direction' => 'descend' },
limit => $n } ];
***** CONTEXT.PM.ORG
{ blog_id => $blog_id, visible => 1 },
{ 'sort' => 'created_on',
direction => 'descend',
unique => 1,
limit => $n } ];
*****
・・・でも、これでどうして順序が直るのか僕には判らないわけで・・・
