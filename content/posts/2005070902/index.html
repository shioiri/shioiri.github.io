Movable Type をバージョンアップ。
ダイナミックページ生成という、なんだかよくわからないけど、スゴそうな機能を使うため、データベースを PostgreSQL から MySQL に変更しました。
データベースについてはまったく知識がないので、データの移動も非効率的。
まったくのクリーンインストールを行い、Movable Type の機能を使ってインポートすることにします。
あ、パーマリンクもみーんな変わっちゃうけど、、、まぁいいか。。。
