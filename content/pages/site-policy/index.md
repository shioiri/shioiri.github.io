## 運営者

このサイトは、塩入友広が個人で運営しています。

## このサイトが収集する情報

このサイトは、コメント欄、問い合わせフォーム、Cookie、アクセス解析を使用していません。運営者が閲覧者の個人情報を収集することはありません。

## サイトの公開に使用しているサービス

このサイトは、GitHub, Inc. が提供する GitHub Pages で公開しています。GitHub Pages のサイトが閲覧されると、閲覧者の IP アドレスがセキュリティ上の目的で GitHub により記録・保存されます（[GitHub Pages について](https://docs.github.com/ja/pages/getting-started-with-github-pages/what-is-github-pages)）。この情報の取り扱いは、[GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement)に従います。

## 外部のサーバーから読み込む内容

一部の記事は、画像、地図、動画などを外部のサーバー（Netlify、Google マップ、YouTube、theLetter など）から読み込んで表示しています。これらを表示する際、閲覧者のブラウザから各サービスの提供者に、IP アドレス等の情報が送信されます。その取り扱いは、各提供者の方針に従います。

## 旧サイトから転載したコメント

旧サイト（smile.shioiri.jp）に寄せられたコメントのうち、公開されていたものを、表示名・日時・本文に限って転載しています。メールアドレス等の公開されていなかった情報は掲載していません。

ご自身のコメントの削除を希望される場合は、運営者までご連絡ください。（連絡先：[shioiri@gmail.com](mailto:shioiri@gmail.com)）

## このサイトの内容の利用 {: #license }

このサイトの文章と写真は、特に記載のあるものを除き、[クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/deed.ja)の条件で利用できます。
著作者名（塩入友広）を表示するなど、ライセンスの条件に従えば、複製、改変、再配布、営利目的での利用ができます。

ただし、次のものは対象外です。

- 旧サイトから転載したコメント（著作権は各コメントの投稿者にあります）
- 引用した文章、他者が作成した画像・資料
- 他者が作成したポスター、チラシ、マッチ箱などの印刷物や作品を撮影・複写した写真
- 外部のサーバーから読み込んで表示している地図、動画など

これらを利用する場合は、それぞれの著作者の許諾が必要になることがあります。
